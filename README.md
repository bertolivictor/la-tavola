> ⚠️ **Projeto fictício.** A Pizzaria La Tavola não existe. Este é um trabalho de **portfólio**, sem fins comerciais — não há endereço, telefone, pedidos ou estabelecimento reais. Os botões de delivery são apenas ilustrativos.

## ☕ Sobre

A **La Tavola** é uma vitrine digital de uma pizzaria napolitana de fermentação natural e forno a lenha. O foco do projeto foi explorar uma estética **escura e sofisticada** ("dark premium"), na qual a fotografia das pizzas é a protagonista e salta sobre o fundo escuro.

O site é uma SPA (single-page application) com quatro "páginas" — **Home, Cardápio, Sobre e Contato** — navegáveis sem recarregar, com transição suave entre elas.

## ✨ Funcionalidades

- 🗂️ **Multi-página** com navegação por estado e transição em fade
- 🍕 **Cardápio filtrável** por categoria (Clássicas, Especiais, Brancas)
- 🌙 **Tema escuro premium** com tipografia serifada e acentos quentes
- 🎞️ **Animações** de entrada no scroll, hover com zoom nas fotos e nav que escurece ao rolar
- 🛵 **Modais de delivery** (iFood / WhatsApp) que avisam, na cor de cada app, que o site é fictício
- 📱 **100% responsivo**, com menu hambúrguer no mobile
- 🥇 **Logo em medalhão circular** com fundo transparente sobre o tema escuro

## 🤖 Sobre as imagens (geradas por IA)

> Todas as **fotos das pizzas** deste projeto foram **geradas por Inteligência Artificial** — nenhuma é foto de comida real.

As imagens foram criadas com o **Nano Banana (Google Gemini 2.5 Flash Image)**, a partir de prompts detalhados de fotografia gastronômica profissional. Para manter o conjunto **visualmente consistente** (essencial para o grid do cardápio), todas seguiram o mesmo padrão:

- Vista **de cima (top-down)** e enquadramento quadrado para o cardápio
- Ângulo **45°** com vapor e iluminação dramática para as pizzas em destaque
- Mesma **superfície de ardósia escura** e mesma luz de estúdio em todas

A consistência foi reforçada gerando uma primeira imagem aprovada e usando-a como **referência** para as demais, trocando apenas os ingredientes de cada sabor.

O **logotipo** representa a identidade visual fictícia da marca.

## 🛠️ Tecnologias

- **React 18** — interface e estado
- **Vite 5** — build e dev server
- **lucide-react** — ícones
- **CSS puro** — sem framework de estilos; todo o tema (cores, animações, layout) é escrito à mão
- **Google Fonts** — *Fraunces* (títulos) + *Hanken Grotesk* (texto)
